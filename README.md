# پیشرو وام — پلتفرم وام و خرید اقساطی | نمونه‌کار Next.js

نسخه بازطراحی‌شده و مستقل از یک پلتفرم لندتک ایرانی، ساخته‌شده با **Next.js 14 (App Router) + TypeScript + Tailwind CSS + Lucide Icons + Recharts** و آماده انتشار روی **GitHub Pages** با Static Export.

> **نسخه دمو / Portfolio:** این پروژه یک نمایش کامل قابلیت‌هاست؛ تمام داده‌ها در `localStorage` مرورگر ذخیره می‌شوند و Backend واقعی ندارد (محدودیت طبیعی هاست استاتیک GitHub Pages).

## 🚀 دمو زنده

- **سایت:** https://rasoolbahadran-stack.github.io/pishro-vam/
- **پنل مدیریت:** https://rasoolbahadran-stack.github.io/pishro-vam/admin/ — نام کاربری: `admin` | رمز: `admin123`

## ✨ امکانات

### سایت عمومی (RTL / فارسی / فونت Vazirmatn)
- **صفحه اصلی** با ۱۰ بخش داده‌محور: هیرو، محاسبه‌گر وام (فرمول استهلاک واقعی + جدول اقساط + نمودار توزیع)، خدمات، آمار، مراحل کار، ویژه عاملین، طرح‌های وام با مقایسه، نظرات، سؤالات پرتکرار، CTA
- **لندتک** + ۴ زیرصفحه: BNPL (جستجوی فروشگاه + محاسبه‌گر)، کارت اعتباری (کارت مجازی تعاملی با flip، کنترل‌ها، تراکنش‌ها با فیلتر و خروجی CSV)، امتیاز اعتباری (گیج، روند ۸ ماهه، رادار عوامل)، سرمایه‌گذاری (محاسبه‌گر سود + سبد)
- **خرید اقساطی**، پورتال **پزشکان** (CRUD خدمات)، پورتال **پذیرندگان** (تسویه + خروجی CSV)، پورتال **سازمان‌ها** (کارکنان با فیلتر + طرح‌های رفاهی)
- **جریان کاربر:** ورود OTP نمایشی، ثبت درخواست وام ۴ مرحله‌ای با قرارداد و کد پیگیری، داشبورد با پرداخت اقساط نمایشی، اعلان‌ها، پروفایل، پشتیبانی
- SEO (متادیتا + OG + JSON-LD + sitemap + robots)، Accessibility (ARIA، فوکوس، Reduced Motion)، کاملاً Responsive

### پنل مدیریت (`/admin`)
- **داشبورد** با آمار و نمودارها (Recharts)
- **بخش‌های سایت:** جابه‌جایی با **Drag & Drop**، فعال/غیرفعال‌سازی، ویرایش عنوان/متن/تصویر/CTA — تغییرات **بلافاصله در صفحه اصلی** اعمال می‌شود
- **صفحات:** وضعیت انتشار (منتشر شده/پیش‌نویس)، نمایش در منو، ویرایش عنوان و توضیحات SEO
- **محتوا:** CRUD کامل خدمات/نظرات/سؤالات/طرح‌ها با جستجو و فیلتر وضعیت
- **رسانه:** آپلود تصویر (dataURL)، افزودن با URL، ویرایش نام/Alt، پیش‌نمایش، حذف، کپی
- **درخواست‌ها:** تأیید/رد درخواست‌های کاربران (منعکس در داشبورد مشتری)
- **تنظیمات:** نام سایت، لوگو، شعار، تماس، شبکه‌های اجتماعی، **تغییر رنگ برند** (۴ پالت) و بازنشانی داده‌های دمو

## 🛠 توسعه محلی

```bash
npm install
npm run dev        # http://localhost:3000
```

## 📦 ساخت نسخه استاتیک (GitHub Pages)

```bash
npm run typecheck
NEXT_PUBLIC_BASE_PATH=/pishro-vam npm run build   # خروجی: out/
```

- `output: 'export'` + `trailingSlash: true` برای سازگاری با سرو دهی GitHub Pages
- `basePath` از طریق متغیر `NEXT_PUBLIC_BASE_PATH` (در Workflow تنظیم شده است)
- دیپلوی خودکار با **GitHub Actions** (`.github/workflows/deploy.yml`) پس از هر push به `main`

## 🏗 معماری

```
app/                    # صفحات (App Router) — عمومی + admin/*
components/
  layout/               # هدر، فوتر، کنترلرهای client
  home/                 # بخش‌های صفحه اصلی (داده‌محور)
  ui/                   # اجزای مشترک (Modal، StatCard، Reveal، …)
lib/
  store.tsx             # Context + localStorage — هسته اتصال پنل به سایت
  types.ts / data.ts    # تایپ‌ها و داده‌های Seed
  format.ts             # اعداد فارسی، محاسبات وام و جدول اقساط
```

**پیشنهاد ارتقا:** برای استقرار با Backend واقعی، لایه `lib/store.tsx` با API Routes یا یک CMS (مثلاً Sanity/Strapi) جایگزین شود؛ ساختار داده‌محور بخش‌ها عیناً قابل نگه‌داشتن است.

## ⚠️ محدودیت‌های نسخه دمو

- بدون Backend: احراز هویت، OTP، پرداخت و ارسال تیکت **شبیه‌سازی‌شده** هستند (کد OTP نمایشی: `123456`)
- داده‌ها در `localStorage` ذخیره می‌شوند و بین دستگاه‌ها منتقل نمی‌شوند؛ آپلود رسانه محدود به تصویر ≤ ۴۰۰KB است
- شماره‌ها و آمارها، داده نمایشی هستند و ارزش واقعی مالی ندارند
